# daily-agent

وكيل يومي شخصي ذكي يعمل على GitHub Actions ويرسل رسائل تحفيزية ومتابعة عبر تليجرام.

## الفكرة

الوكيل يعرف عنك معلومات أساسية محدودة فقط (الاسم + التخصص + بعض الاهتمامات)، ثم يبني معرفته تدريجياً من خلال التفاعل.

حالياً يعمل باتجاه واحد (يرسل رسائل مفاجئة)، والذاكرة جاهزة للتوسع لاحقاً.

## الملفات المهمة

| الملف | الوظيفة |
|------|--------|
| `bot.py` | الكود الرئيسي للوكيل |
| `profile.json` | المعلومات الثابتة عنك (الاسم، التخصص، الاهتمامات) |
| `memory.json` | الذاكرة المتراكمة (حقائق، مواضيع، ملاحظات تقدم) |
| `.github/workflows/reminder.yml` | جدولة التشغيل |

## كيف يعمل؟

- يعمل 4 مرات يومياً في أوقات مختلفة + تأخير عشوائي (حتى 45 دقيقة) حتى لا تكون الرسالة متوقعة.
- يعرف اليوم الحالي والوقت (توقيت الأردن).
- يقرأ ملف الشخصية والذاكرة قبل توليد الرسالة.
- يستخدم Gemini لتوليد رسالة طبيعية وقصيرة ومتنوعة.
- في حال فشل النموذج، يرسل رسالة احتياطية بسيطة.

## تخصيص الوكيل

عدّل ملف `profile.json` ليحتوي معلوماتك الأساسية فقط.

ملف `memory.json` يبدأ فارغاً تقريباً. لاحقاً يمكن تطوير الوكيل ليحدثه تلقائياً أو يقرأ ردودك.

## الأسرار المطلوبة (GitHub Secrets)

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `GEMINI_API_KEY`

## التشغيل اليدوي

من تبويب Actions → Random Daily Agent → Run workflow
